01 / What we heard

Three patterns. Tested with the College on October 27.

1

Same course, different experience.

AI rules, marking and Brightspace change from prof to prof.

2

No practice time outside class.

Locked labs. Laptops that can’t run the software.

3

Keeping up with industry.

Job postings ask for tools and AI skills classes barely cover.

What we learned about how the College changes.

$1M+

a year into renewing equipment, says the College. They’re trying to add more this year.

99%

of program changes happen inside courses. Profs can update content, resources and assessments any time.

5 to 7

years between full program reviews.

3

years of program council minutes get read in a program review.

Emails to the president don’t move things. Program councils do.
